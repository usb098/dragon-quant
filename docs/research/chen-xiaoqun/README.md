# 陈小群资料蒸馏 v0.3 — 派生研究资料

本目录只包含用户授权公开的派生结构化研究内容；不含原始 PDF、PNG、ZIP、视频、网盘链接或账号凭证。该 GitHub 仓库为公开仓库，目录中的派生数据也将公开可见。

## 证据边界
- A-candidate：候选账号/软件截图，仅代表可辨认画面字段；账号身份、截图完整性未独立核实。
- B：整理者引用、观点归纳或案例重建，不等同于本人逐字原话或完整券商流水。
- C：2025 年逐日整理稿，包含作者观察与推测，不等于已核实成交。
- D：二手研究，仅能产生待验证假设。
- 所有理念均为 research_only，不代表已经验证的盈利规律。

## 文件
- principles.v0.3.json：14 条原子原则。
- case-evidence.v0.3.json：关键案例证据索引与限制。
- events-2025-summary.v0.3.json：2025 年逐日整理稿的聚合行为假设。
- visible-orders-2022.v0.3.json：经截图可见字段抽取的委托片段；明确区分委托量和成交量。

## 不可越界
该专家只生成模式观察、阻断条件和待补证据。不会生成买卖价格、仓位、自动下单或胜率承诺。验证必须按市场阶段和模式分层、走时间样本外测试、计入费用/滑点/无法成交与幸存者偏差。
